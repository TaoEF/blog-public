# Small Change Workflow

Use for local, low-risk changes.

1. Read `.harness/index.md` and `.harness/catalog.md`.
2. Read relevant `.project-wiki/` pages.
3. Inspect the immediate code path.
4. Make the smallest compatible change.
5. Keep one main variable changing at a time.
6. Run narrow verification.
7. Update wiki if durable knowledge changed.
